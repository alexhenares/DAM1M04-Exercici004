# Exercici 004 - Strata

## Autors
- Sergio Moreno
- Alex Henares

## Descripció
En aquest exercici hem reproduït la pàgina web principal de Strata utilitzant HTML i CSS.

Hem intentat que el disseny sigui el més semblant possible a les imatges de referència proporcionades pel professor.

## Tecnologies utilitzades
- HTML
- CSS
- Flexbox
- JavaScript (animació proporcionada pel professor)

## Disseny responsive
Hem adaptat la pàgina perquè es pugui visualitzar tant en ordinadors com en dispositius mòbils, utilitzant media queries.

## Com executar el projecte
Per visualitzar la pàgina en local, cal obrir el fitxer `index.html` amb Live Server des de Visual Studio Code.

Un cop publicada al servidor Proxmox de l’institut, també es podrà veure des del navegador a:
